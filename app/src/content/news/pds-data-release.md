行星数据系统（Planetary Data System，PDS）是 NASA 主导的行星探测数据长期归档与分发平台，涵盖从早期先驱者、旅行者任务到现役火星车、轨道器的几乎全部美国行星任务数据。

本轮季度更新中，PDS 各学科节点新增了一批经过定标与质量校验的数据产品，包括火星轨道器高分辨率影像的季度增量、外行星探测任务的重新定标数据，以及若干小行星任务的光谱派生产品。多个节点同步更新了数据字典与文档，进一步改善了数据的可发现性。

值得关注的是，新归档数据已全面采用 PDS4 信息模型标准。该标准以 XML 标签描述数据结构与元数据，使数据产品具备机器可读的自描述能力，便于通过 API 批量获取与自动化处理。旧版 PDS3 数据的迁移工作也在持续推进。

对于国内研究者而言，PDS 与欧空局 PSA、日本 DARTS 等归档系统之间保持着镜像与互操作机制，绝大多数数据无需注册即可免费下载。社区同时提供了一系列开源工具，用于 PDS4 标签解析与常见数据格式的读写。
