## 用 Playwright 实际抓取并重建 sanctuary 逐帧编排（DOM 探针法）
- 用户问"你能自己抓还是得我录屏"→ 决定自抓。环境验证：本机原无 Playwright/Chromium，但网络通；已装 Playwright 库 + Chromium 到托管 node22.22.2 workspace（`/Users/etteraug/.workbuddy/binaries/node/workspace`，Chromium 落在 `~/Library/Caches/ms-playwright`）。无头 Chromium 用 SwiftShader 软件渲染 WebGL 可用（`WebGL 1.0 | WebKit WebGL`）。
- 关键发现：该站**不滚动 window**（documentElement 高仅 900=一屏），改用虚拟滚动容器 `.Site-scrollmain` 靠 `transform: translateY` 平移；GSAP/Lenis 均未挂全局（Nuxt 闭包打包），无法直接调 ScrollTrigger.progress。故 `window.scrollTo` 完全无效（实测 scrollY 恒 0）。
- 解法：用 `page.mouse.wheel` 派发真实滚轮事件驱动虚拟滚动（库监听 wheel），轮询 `.Site-scrollmain` 的 translateY 到目标进度；每桶截图 + DOM 探针提取各 section 的 `getBoundingClientRect().top` / `getComputedStyle().opacity` + 视口可见 `h1/h2/h3/p` 文字。0→100% 分 24 桶，共 25 帧。
- 重建编排（详见 `timeline.json` 与 `对标站_视觉编排分析.md`）：0-8% Hero+赞助人(Macron)；21-29% HomeContext 标语；≈30-33% 月球 `HomeMoonCircles` opacity 0→1 淡入(主角延迟登场)；33-46% HomeDiscs(24 DISCS MADE OF SAPPHIRE)；54-67% 圆盘基因说明；67-83% HomePictures(GENOME SCIENCE ART)；92-100% footer。手法：主角延迟登场 / 文字成段随滚动浮现 / 视差分层(月球反向 +718 vs 容器 -718) / 长背景层贯穿前段。
- 限制：①本模型不支持读图，分析基于 DOM 文本数据而非像素（截图仅供用户肉眼校对）；②代理网络并发受限，部分图片/字体/3D 贴图 401/连接关闭缺失（时序/布局/文字/opacity 不受影响）。
- 交付：`playwright_capture/capture_frames.js`(脚本)、`playwright_capture/frames/`(25 图+timeline.json+index.html 帧预览)、`对标站_视觉编排分析.md`(项目根分析文档)。未改首页代码。
- 方法论沉淀：本环境已具备"Playwright + DOM 探针重建对标站动画编排"能力；目标站滚动机制每次不同需定制脚本，但模板可复用。
